LogicBuilding101 is a curated collection of **101+1 problems** to build programming logic from scratch, structured as a **34‑day** plan (3 problems per day).

## Categories (from LogicBuilding101)

1. Basic Math Problems  
2. Basic Patterns  
3. Intermediate Math Problems  
4. Medium Patterns  
5. Arrays  
6. Matrix  
7. Strings  
8. Objects  
9. Basic Recursion  

## How it works in this project

- **Timeline:** Day 1 → 3 problems, Day 2 → next 3, … Day 34 → last 3 (102 total).
- **In the app:** When you open a day (1–34), the “Logic Building 101” topic shows that day’s 3 problems from `questions.md`.
- **Full problems and solutions:** For full problem text and code (e.g. JavaScript), see the original repo:  
  [https://github.com/Upendhar10/LogicBuilding101](https://github.com/Upendhar10/LogicBuilding101)  
  Each day has a `Questions.md` and `Solutions.js` in `DAY01/` … `DAY34/`.
