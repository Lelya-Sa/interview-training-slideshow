# Logic Building 101 – Questions (102 problems)

*Source: [LogicBuilding101](https://github.com/Upendhar10/LogicBuilding101) by Upendhar10. Used with credit.*

Format: 34 days × 3 problems per day. In the app, Day N shows problems (N−1)*3+1 to N*3.

### 1. Program to Print Integer Numbers Entered by the User
**Answer:** Write a program where the user enters an integer and the program prints that number back. Example: Input `42` → Output `You entered: 42`. Full problem and solution code: [LogicBuilding101 DAY01](https://github.com/Upendhar10/LogicBuilding101/tree/main/DAY01).

### 2. Find the Size of int, float, double, and char
**Answer:** Write a program that displays the size (in bytes) of `int`, `float`, `double`, and `char` on your system. Example output: Size of int: 4 bytes, float: 4, double: 8, char: 1. [LogicBuilding101 DAY01](https://github.com/Upendhar10/LogicBuilding101/tree/main/DAY01).

### 3. Find the Larger Number Among Two Numbers
**Answer:** Compare two integers entered by the user and print the larger one. Example: Input 15, 20 → Output "The larger number is: 20". [LogicBuilding101 DAY01](https://github.com/Upendhar10/LogicBuilding101/tree/main/DAY01).
