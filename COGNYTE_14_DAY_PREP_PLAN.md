# Cognyte Fullstack Frontend Interview Prep (14 Days)

Target profile: Junior frontend/fullstack candidate (React + Angular + JS + logic/LeetCode).

## How to Use This Plan

- Follow day by day without skipping.
- Keep one notebook: `mistakes`, `weak-topics`, `repeat-questions`.
- Every 2 days, run verification before moving forward.
- If verification fails, repeat weak blocks next morning (60-90 minutes).

Goal: Build strong React/Angular/JS basics and interview confidence.

### Day 4 - API + Async in Both Frameworks

- [ ] Coding: 3 logic tasks (sorting + binary search basics).
